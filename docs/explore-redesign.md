# Explore 刷新（確定版・2026-08-28）

いまの Explore を「提案」と「実行」の2本の柱に組み直す。
**生成の仕組み・データモデル・KEEP/SKIP の記録・今日を終える処理は一切変えない。**
変えるのは見せ方と操作だけ。

---

## 0. 言葉の方針（最優先）

- **画面に出る文字は一般語**。「提案 / ストック / マップ / プラン」。
- メタファー（鉄道・券・案内標）は**視覚だけ**で表現する。
  「本日の販売は終了しました」のような言い回しは使わない。
  空の状態は「今日の提案は以上です」程度の普通の文にする。
- 英字のラベル（`STOCK` / `VIA` / `TERM` など）はサインの語彙として使ってよい。

## 2. 券 ── 唯一の共通部品

1件＝1枚の券。場所によって**縮尺だけ**が変わる。

### ★組み方の正は **Vitsœ のラベル**（2026-08-28 にユーザー確定）

参照は3枚（AuBe のポスター／**Vitsœ のラベル**／Grilli Type の名刺）。
3枚に共通しているのは次の5つで、券はこれに従う。

1. 地は**紙か、ベタ1色**。券は**その色の紙そのもの**になる。
2. **文字は全部黒**。階層は色ではなく**大きさだけ**が作る。
3. **太い黒バー**か**極細の罫**で区画を割る。箱で囲わない。
4. **巨大な要素が1つだけ**。券では**題**（ユーザー確定）。
5. 色は幾何形か全面のどちらか。**文字には使わない**。

### 版面（幅 300 / 比 13:21 → 高さ 485）

```
　　　　　　　　　　　　　　　　　　  ← 全面がドメイン色の紙（紙の目を焼いてある）
  EXHIBITION              Nº 0143    nano caps ／ 通し番号
  ──────────────────────────────     罫（黒・1px）

  ┌────────────────────────────┐
  │           写真              │     ★周囲に余白をとった四角（裁ち落とさない）
  └────────────────────────────┘

  見えないものたちの庭                ★主役。display(26)/bold、最大2行
  音と光だけで構成された9つの部屋を…    body(13)、最大2行

        （余白は題の上下へ 3:5 で割る）

  ──────────────────────────────     罫
  会期      12.02 – 03.16            ラベル(和 micro ＋ 欧 nano) ／ 内容(body)
  SOON
  会場      東京都現代美術館・清澄白河
  VENUE
  ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘    ミシン目（穿孔）
  EXPLORE                 ▮▯▮▮▯     半券
```

- **段は3つだけ** … 題 `display`(26) ／ 内容 `body`(13) ／
  ラベル 和 `micro`(9)＋欧 `nano`(7)。比は 2.0 と 1.44 で design.md §5-2 を満たす。
- **余白は題の上下へ 3:5 で割る。** 片側だけに逃がすと、写真が無い券で
  中央がぽっかり空く（3巡目に実際にそうなった）。
- 期限が近いことは**色ではなくラベルの語**で伝える（`PERIOD` → `SOON`）。
  有彩色は紙の1色しか使わない。
- ★題と要約は `flexShrink: 0`。縮むと `-webkit-box` が**字の途中で切れる**。

### 紙の色 ── 黒が載る明るい4色

券は色紙になり黒い文字が載るので、**暗い色は使えない**
（forest / violet / wine の上では黒が沈む）。`SCHEME` の明るい4色を当てる。

| ドメイン | 色 |
|---|---|
| バショ `place` | sky `#509BF5` |
| タイケン `experience` | pink `#F76FA1` |
| ジョウホウ `info` | yellow `#F5E837` |
| モノ `thing` | orange `#FA6E31` |

### 紙のテクスチャは**下地**に

`public/paper-kraft.webp`（図形が焼き込んでいるのと同じ1枚）を
**色のすぐ上・文字の下**に `mix-blend-mode: multiply` で敷く。等倍・繰り返しなし
（★縮小しない。紙の目は高周波なので消える）。
★最前面に `overlay` で乗せると**写真も文字も霞む**（2巡目に実際にそうなった）。

### 券種（データの出自）
| 券種 | ラベル |
|---|---|
| 提案 | 券種の欧文（`EXHIBITION` / `BOOK` / `FOOD` …） |
| 入力（自分で書いた／声から拾った） | `SELF ISSUED` |

★「自分で書いた」と「声から拾った」は**同じもの**。手動か AI かの違いだけ。

### 鋏痕（入鋏の痕）
★**券の縁を切り欠く**形。大きさは**券の幅の 18%**。
★★券が彩度の高い紙になったので、切り欠きは**地との差だけで読む**。
2巡目の「奥ほど暗い影」の細工は要らない。32% は紙を食い荒らして版面が壊れた。

**4ドメイン**に対応する4つの形。

| ドメイン | 形 |
|---|---|
| バショ `place` | 半円 |
| タイケン `experience` | 三角（V字） |
| ジョウホウ `info` | 角型 |
| モノ `thing` | 二山（W） |

**鋏痕は3か所で同じ意味を持つ**（文字を使わない分類）:
1. 券の縁の切り欠き 2. マップ上のノードの形 3. ストックの絞り込みアイコン

★陰は**口を除いた輪郭**（`notchContour`）にだけ落とす。閉じた輪郭を縁取ると
**券の縁そのものにも線が乗り**、切れ目ではなく「置かれた図形」に見える。

## 2-b. 改札鋏（`components/explore/Nipper.tsx`）

★**SVG で描く**。CSS の 3D 変形は使わない（design.md 冒頭）。

### 形の正 ── 一体成型のステンレスの改札鋏

プライヤではない。長い**涙形のループの柄**（帯そのものがバネ）と、その先の
**厚い頭**。動くのは**上の顎だけ**で、下の顎と黒い樹脂の受けはループと一体で
動かない（実物の1穴パンチと同じ）。頭が全長の 4 割ほど。
★頭を小さくすると受け・抜き型・鋲が1つの塊に潰れて、何の工具か分からなくなる。

### 描き方の正 ── Sony Walkman のイラスト

1. **輪郭線を1本も引かない。** 面は明暗だけで分かれる。
2. 立体は**押し出し** … 同じ輪郭を右下へずらして `side` で置くと厚みになる。
3. 稜線の光は**左上の三日月** … 輪郭で切り抜いた中に `lit` を敷き、その上に
   `face` を右下へ少しずらして重ねると、左上だけに光の帯が残る。
4. 影は**ぼかさない1枚の面**。輪郭をまとめて大きくずらすだけ。
5. 階調は**無彩色の3つ**（`lit`/`face`/`side`）＋黒い受け＋抜き型のドメイン色。

この5つを `Part` という1つの部品にまとめてあるので、輪郭を1本足せば
同じ質感で増やせる。

### 構図

一人称。頭が左上（券の方）を向き、**ループの柄は画面の右下へ抜ける**
（そこに手がある）。長軸は垂直から -26°。
★-38° まで倒すと柄が画面の**右へ**すぐ抜け、柄が1つも見えない（2巡目に実測）。
★券には重ねない。掴んで寄せるのが操作なので、待機の位置は券の下。

## 3. 提案（TODAY）

- 券が1枚。右下に**改札鋏**（SVG で立体的に描く。CSS の 3D 変形は使わない）。
- 鋏をドラッグして券に近づけると**一番近い縁に吸い付き**、離すとそこが切り欠かれる＝残す。
- 券は落ちて次が出る。何もしなければ送って流す。
- タップで券が伸びて詳細。
- 下端に**束の厚み**が見えていて、入鋏した券がそこへ落ちる。

## 4. ストック（STOCK）

- 入鋏済みの券が格子に並ぶ。**画像主体**、数百件に耐える。
- 絞り込みは**鋏痕の形**。
- 会期が近い券は縁が変わり、切れた券は落ちる。
- 券をタップ＝原寸に戻る。

## 5. マップ（NETWORK）

- 目標とする見た目は Vignelli の NYC 路線図系：
  **太い等幅の線が平行に走り、角は大きな円弧、駅は黒丸、乗換は白い抜き。**
- ノードの形＝鋏痕。1駅に複数件が付く場合に対応する。
- 駅をタップ→券のピンが立つ。**中央ほど大きく写真つき、端ほど小さい（LOD）**。
- 絞り込むと図が**必要な分だけに変形**する（レイアウトは決定的。前後を補間）。
- **県が違えば別の島**にして破断線で繋ぐ（距離では判定しない）。

## 6. プラン（BOARD・重ねる）

- 下から引き上げるオーバーレイ。
- 今日の行程／プラン生成（3案）／保存したプラン。
- 3案は図の上に薄く重なって見比べられる。

## 7. デザインの制約（design.md より）

- **CSS の 3D 変形（`perspective` / `rotateX` / `rotateY`）は使わない。**
  立体感は SVG / canvas で「描く」。
- Framer Motion・`layoutId`・Tailwind も使わない。
- 券の紙は既存の `PAPER`（中性のグレー）。第33巡で暖色のクリームは廃止済みなので
  戻さない。紙らしさは**地紋と繊維の目**だけで出す。
- 余白・文字・角丸は `lib/tokens.ts`、色は `lib/constants.ts` から引く。
  図形の座標は「目盛りの外」として印を付ける。
