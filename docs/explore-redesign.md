# Explore 刷新（確定版・2026-08-28）

いまの Explore を「提案」と「実行」の2本の柱に組み直す。
**生成の仕組み・データモデル・KEEP/SKIP の記録・今日を終える処理は一切変えない。**
変えるのは見せ方と操作だけ。

## 0. 言葉の方針（最優先）

- **画面に出る文字は一般語**。「提案 / ストック / マップ / プラン」。
- メタファー（鉄道・券・案内標）は**視覚だけ**で表現する。
  「本日の販売は終了しました」のような言い回しは使わない。
  空の状態は「今日の提案は以上です」程度の普通の文にする。
- 英字のラベル（`STOCK` / `VIA` / `TERM` など）はサインの語彙として使ってよい。

## 2. 券 ── 唯一の共通部品

1件＝1枚の券。場所によって**縮尺だけ**が変わる。

### ★券がこのアプリの一員であるための4つの条件（第69巡に確定）

最初に作った券は「ただのカード」に見えた。原因は**アプリの語彙を1つも
使っていなかった**こと。TASK の実物（GRAVITY の `FRIDAY 8/28`）は
**巨大な文字・裸の地・本物の紙の目**で出来ている。券もそれに揃える。

1. **主役は1つ、巨大に。** 期限の日付を `SWISS_XL`(72) で組む。
   これは TIMELINE の曜日と**同じ段**で、design.md §7 が認めている
   「表示専用の巨大欧文」。行間は `0.86`（`LEAD.flat` では緩い）。
2. **役は4つまで**（design.md §5-1）。
   主＝期限 / 従＝題(`TYPE.display`) / 付帯＝要約と会場(`TYPE.body`) /
   ラベル＝券種と通し番号(`TYPE.nano` の欧文大文字)。
3. **罫は2本だけ。** 写真の下と、半券の上のミシン目（破線ではなく**穿孔**＝
   丸の列）。箱で囲わず、束ねるのは余白でやる（束の中 `xs`〜`md`、束の間 `lg`）。
4. **紙は本物の写真。** `public/paper-kraft.webp`（`lib/paperTexture.ts` が
   図形へ焼き込んでいるのと**同じ1枚**）を CSS の背景に等倍で敷き、
   `mix-blend-mode: overlay` で凹凸だけを乗せる。★縮小しない（紙の目は
   高周波なので消える）。偽の縞（`repeating-linear-gradient`）は使わない。

縦横比は **13/21**（0.619）。5/7 はカードの比で、これが「カードに見える」
直接の原因だった。

### 券面の構成
```
写真（左右上とも裁ち落とし・券の高さの 36%）
────────────────────────────── 罫1
EXHIBITION                    ▼   ラベル ／ 分類の印（鋏痕と同じ形）
見えないものたちの庭                 従
音と光だけで構成された9つの部屋を…      付帯（2行）
        （余りはここへ逃がす）
UNTIL
03.16                              ★主役
東京都現代美術館・清澄白河             付帯
∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘   ミシン目（穿孔）
NO 0143              ▮▯▮▮▯▮▯     半券
```

- **写真が無い券**は写真の枠が分類色のベタ面になり、漢字1文字が透かしとして
  `SWISS_XL` で入る。券がそのまま**ポスター**になる。
- ★題と要約は `flexShrink: 0`。縮ませると `-webkit-box` が**字の途中で切れる**。

### 券種（データの出自）
| 券種 | 中身 | 見た目の差 |
|---|---|---|
| 提案 | AI が夜に作ったカード | ラベルが券種の欧文 |
| 入力 | 自分で書いた、または声から AI が拾った項目 | ラベルが `SELF` |
| 記事 | 情報カード | 読んだら使用済みの印 |
| 継続 | ゴール | 期間を持つ券 |
| 使用済み | 実行した券 | 色が落ちる（アーカイブ側） |

★「自分で書いた」と「声から拾った」は**同じもの**。手動か AI かの違いだけ。

### 鋏痕（入鋏の痕）
★**券の縁を切り欠く**形。紙の中に穴を開けるのではなく、端から食い込ませて切る
（実物の改札鋏の鋏こんと同じ）。大きさは**券の幅の 32%**。

**4ドメイン**（`domainOf` が唯一の分類の入口）に対応する4つの形。

| ドメイン | 形 |
|---|---|
| バショ `place` | 半円 |
| タイケン `experience` | 三角（V字） |
| ジョウホウ `info` | 角型 |
| モノ `thing` | 二山（W） |

10 種類の `kind` はラベルの欧文が担う。鋏痕は小さく描かれるので4つに絞る。

**鋏痕は3か所で同じ意味を持つ**（文字を使わない分類）:
1. 券の縁の切り欠き 2. マップ上のノードの形 3. ストックの絞り込みアイコン

★★**切り口は「地の色」だけでは見えない。** 券の紙(`#FAFAF9`)と地(`#F0F0EE`)は
ほとんど同じ明るさだから。切り欠きは
①地を塗り ②**奥ほど暗くなる影**（`TICKET_SHADE`）を重ね
③**口を除いた輪郭**（`notchContour`）だけを縁取る、の3段で読ませる。
★閉じた輪郭を縁取ると**券の縁そのものにも線が乗り**、切れ目ではなく
「置かれた図形」に見える。

## 2-b. 改札鋏（`components/explore/Nipper.tsx`）

★**SVG で描く**。CSS の 3D 変形は使わない（design.md 冒頭）。
開閉は支点まわりの2Dの回転だけ。

第69巡に描き直して分かった、**工具に見えるための3つの条件**:

1. **柄は顎と反対側に付く。** 支点を挟んだ1本の梃子なので、左の顎を持つ腕の
   柄は**右**に出る（実物の鋏・プライヤと同じ）。同じ側にすると開いたときに
   柄どうしが**交差**して1つの塊になり、工具に見えない。
   **開いた柄のあいだにできる三角の空きが、いちばん強い手掛かり。**
2. **頭は軸をまたがない。** 2つの頭は軸の左右に分かれて向かい合い、そのあいだの
   隙間＝**喉**が先で口を開く。ここへ券の縁を差し込む。両方が軸をまたぐと
   互いに重なり、紙の入る隙間がどこにも無くなる。
3. **胴は細く、先で段を付けて厚い頭になる。** 段が無いと先が広がった「ヘラ」に
   見える。頭は全長の 1/4 ほど（実物の比）。

テイストは**ベクター**。グラデーションは1つも使わない ―
面ごとに1色（`lit`/`face`/`side` の3面）を置き、**均一な太さの輪郭**で締め、
影もぼかさず**ずらした同形の面を1枚**敷くだけ。
★鋼の明るさは地(`#F0F0EE`)より**はっきり暗く**する。近いと輪郭だけの
「白い塊」になる。彩色は `NIPPER_PAINT`（図形専用のパレット）。

構図は**一人称**。長軸は垂直から **-26°**、柄は画面の**下端**へ抜ける
（そこに手がある）。★-38°まで倒すと柄が画面の**右へ**すぐ抜け、
握りが1つも見えない。

## 3. 提案（TODAY）

- 券が1枚。右下に**改札鋏**（SVG で立体的に描く。CSS の 3D 変形は使わない）。
- 鋏をドラッグして券に近づけると**一番近い縁に吸い付き**、離すとそこが切り欠かれる＝残す。
- 券は落ちて次が出る。何もしなければ送って流す。
- タップで券が伸びて詳細。
- 下端に**束の厚み**が見えていて、入鋏した券がそこへ落ちる。

## 4. ストック（STOCK）

- 入鋏済みの券が格子に並ぶ。**画像主体**、数百件に耐える。
- 絞り込みは**鋏痕の形**。
- 会期が近い券は縁が変わり、切れた券は落ちる。
- 券をタップ＝原寸に戻る。

## 5. マップ（NETWORK）

- 目標とする見た目は Vignelli の NYC 路線図系：
  **太い等幅の線が平行に走り、角は大きな円弧、駅は黒丸、乗換は白い抜き。**
- ノードの形＝鋏痕。1駅に複数件が付く場合に対応する。
- 駅をタップ→券のピンが立つ。**中央ほど大きく写真つき、端ほど小さい（LOD）**。
- 絞り込むと図が**必要な分だけに変形**する（レイアウトは決定的。前後を補間）。
- **県が違えば別の島**にして破断線で繋ぐ（距離では判定しない）。

## 6. プラン（BOARD・重ねる）

- 今日の行程／プラン生成（3案）／保存したプラン。
- 3案は図の上に薄く重なって見比べられる。

## 7. デザインの制約（design.md より）

- **CSS の 3D 変形（`perspective` / `rotateX` / `rotateY`）は使わない。**
  立体感は SVG / canvas で「描く」。
- Framer Motion・`layoutId`・Tailwind も使わない。
- 券の紙は既存の `PAPER`（中性のグレー）。第33巡で暖色のクリームは廃止済みなので
  戻さない。紙らしさは**地紋と繊維の目**だけで出す。
- 余白・文字・角丸は `lib/tokens.ts`、色は `lib/constants.ts` から引く。
  図形の座標は「目盛りの外」として印を付ける。
