# Explore 刷新（確定版・2026-08-28）

いまの Explore を「提案」と「実行」の2本の柱に組み直す。
**生成の仕組み・データモデル・KEEP/SKIP の記録・今日を終える処理は一切変えない。**
変えるのは見せ方と操作だけ。

---

## 0. 言葉の方針（最優先）

- **画面に出る文字は一般語**。「提案 / ストック / マップ / プラン」。
- メタファー（鉄道・券・案内標）は**視覚だけ**で表現する。
  「本日の販売は終了しました」のような言い回しは使わない。
  空の状態は「今日の提案は以上です」程度の普通の文にする。
- 英字のラベル（`STOCK` / `VIA` / `TERM` など）はサインの語彙として使ってよい。

## 2. 券 ── 唯一の共通部品

1件＝1枚の券。場所によって**縮尺だけ**が変わる。

### 券面の構成
```
帯    分類の丸(漢字) ／ 分類の欧文 ／ 通し番号 ／ 期限
画像  上半分（無ければ地紋の面になり、題が大きく伸びる）
点線  分節（ちぎる線ではない）
題
要約  2行
罫
会場・エリア ／ 会期
```

### 券種（データの出自）
| 券種 | 中身 | 見た目の差 |
|---|---|---|
| 提案 | AI が夜に作ったカード | 印刷された券 |
| 入力 | 自分で書いた、または声から AI が拾った項目 | **手書きの欄**。出自の差は小さな印だけ |
| 記事 | 情報カード | 読んだら使用済みの印 |
| 継続 | ゴール | 期間を持つ券 |
| 使用済み | 実行した券 | 色が落ちる（アーカイブ側） |

★「自分で書いた」と「声から拾った」は**同じもの**。手動か AI かの違いだけ。

### 鋏痕（入鋏の痕）
★**券の縁を切り欠く**形。紙の中に穴を開けるのではなく、端から食い込ませて切る
（実物の改札鋏の鋏こんと同じ）。大きさは券の幅の約1/4。

**4ドメイン**（`domainOf` が唯一の分類の入口）に対応する4つの形。

| ドメイン | 形 |
|---|---|
| バショ `place` | 半円 |
| タイケン `experience` | 三角（V字） |
| ジョウホウ `info` | 角型 |
| モノ `thing` | 二山（W） |

10 種類の `kind` は帯の中の**漢字1文字**（`glyph`）が担う。
鋏痕は小さく描かれるので、判別できる4つに絞る。

**鋏痕は3か所で同じ意味を持つ**（文字を使わない分類）:
1. 券に開いた穴 2. マップ上のノードの形 3. ストックの絞り込みアイコン

## 3. 提案（TODAY）

- 券が1枚。右下に**改札鋏**（SVG で立体的に描く。CSS の 3D 変形は使わない）。
- 鋏をドラッグして券に近づけると**一番近い縁に吸い付き**、離すとそこが切り欠かれる＝残す。
- 券は落ちて次が出る。何もしなければ送って流す。
- タップで券が伸びて詳細。
- 下端に**束の厚み**が見えていて、入鋏した券がそこへ落ちる。

## 4. ストック（STOCK）

- 入鋏済みの券が格子に並ぶ。**画像主体**、数百件に耐える。
- 絞り込みは**鋏痕の形**。
- 会期が近い券は縁が変わり、切れた券は落ちる。
- 券をタップ＝原寸に戻る。

## 5. マップ（NETWORK）

- 目標とする見た目は Vignelli の NYC 路線図系：
  **太い等幅の線が平行に走り、角は大きな円弧、駅は黒丸、乗換は白い抜き。**
- ノードの形＝鋏痕。1駅に複数件が付く場合に対応する。
- 駅をタップ→券のピンが立つ。**中央ほど大きく写真つき、端ほど小さい（LOD）**。
- 絞り込むと図が**必要な分だけに変形**する（レイアウトは決定的。前後を補間）。
- **県が違えば別の島**にして破断線で繋ぐ（距離では判定しない）。

## 6. プラン（BOARD・重ねる）

- 下から引き上げるオーバーレイ。
- 今日の行程／プラン生成（3案）／保存したプラン。
- 3案は図の上に薄く重なって見比べられる。

## 7. デザインの制約（design.md より）

- **CSS の 3D 変形（`perspective` / `rotateX` / `rotateY`）は使わない。**
  立体感は SVG / canvas で「描く」。
- Framer Motion・`layoutId`・Tailwind も使わない。
- 券の紙は既存の `PAPER`（中性のグレー）。第33巡で暖色のクリームは廃止済みなので
  戻さない。紙らしさは**地紋と繊維の目**だけで出す。
- 余白・文字・角丸は `lib/tokens.ts`、色は `lib/constants.ts` から引く。
  図形の座標は「目盛りの外」として印を付ける。
