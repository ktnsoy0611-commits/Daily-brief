# Explore 刷新（確定版・2026-08-28）

いまの Explore を「提案」と「実行」の2本の柱に組み直す。
**生成の仕組み・データモデル・KEEP/SKIP の記録・今日を終える処理は一切変えない。**
変えるのは見せ方と操作だけ。

---

## 0. 言葉の方針（最優先）

- **画面に出る文字は一般語**。「提案 / ストック / マップ / プラン」。
- メタファー（鉄道・券・案内標）は**視覚だけ**で表現する。
  「本日の販売は終了しました」のような言い回しは使わない。
  空の状態は「今日の提案は以上です」程度の普通の文にする。
- 英字のラベル（`STOCK` / `VIA` / `TERM` など）はサインの語彙として使ってよい。

## 2. 券 ── 唯一の共通部品

1件＝1枚の券。場所によって**縮尺だけ**が変わる。

### ★組み方の正は **Vitsœ のラベル**（2026-08-28 にユーザー確定）

参照は3枚（AuBe のポスター／**Vitsœ のラベル**／Grilli Type の名刺）。
3枚に共通しているのは次の5つで、券はこれに従う。

1. 地は**紙か、ベタ1色**。券は**その色の紙そのもの**になる。
2. **文字は全部黒**。階層は色ではなく**大きさだけ**が作る。
3. **太い黒バー**か**極細の罫**で区画を割る。箱で囲わない。
4. **巨大な要素が1つだけ**。券では**題**（ユーザー確定）。
5. 色は幾何形か全面のどちらか。**文字には使わない**。

### 版面（幅 300 / 比 13:21 → 高さ 485）

```
　　　　　　　　　　　　　　　　　　  ← 全面がドメイン色の紙（紙の目を焼いてある）
  EXHIBITION              Nº 0143    nano caps ／ 通し番号
  ──────────────────────────────     罫（黒・1px）

  ┌────────────────────────────┐
  │           写真              │     ★周囲に余白をとった四角（裁ち落とさない）
  └────────────────────────────┘

  見えないものたちの庭                ★主役。display(26)/bold、最大2行
  音と光だけで構成された9つの部屋を…    body(13)、最大2行

        （余白は題の上下へ 3:5 で割る）

  ──────────────────────────────     罫
  会期      12.02 – 03.16            ラベル(和 micro ＋ 欧 nano) ／ 内容(body)
  SOON
  会場      東京都現代美術館・清澄白河
  VENUE
  ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘    ミシン目（穿孔）
  EXPLORE                 ▮▯▮▮▯     半券
```

- **段は3つだけ** … 題 `display`(26) ／ 内容 `body`(13) ／
  ラベル 和 `micro`(9)＋欧 `nano`(7)。比は 2.0 と 1.44 で design.md §5-2 を満たす。
- **余白は題の上下へ 3:5 で割る。** 片側だけに逃がすと、写真が無い券で
  中央がぽっかり空く（3巡目に実際にそうなった）。
- 期限が近いことは**色ではなくラベルの語**で伝える（`PERIOD` → `SOON`）。
  有彩色は紙の1色しか使わない。
- ★題と要約は `flexShrink: 0`。縮むと `-webkit-box` が**字の途中で切れる**。

### 鋏痕（入鋏の痕）

★**券の縁を切り欠く**形。大きさは**券の幅の 13%**。
★★券が彩度の高い紙になったので、切り欠きは**地との差だけで読む**。

**形の正は旧国鉄の鋏こん一覧**（46種・2026-08-28 にユーザー指定）。
一覧を見ると、鋏こんは例外なく「**券の縁が形の上辺**で、そこから下へ食い込む」
形で、輪郭は**直線と単純な弧が2〜4本だけ**。この規律から外れると鋏こんに見えない。

| ドメイン | 形 | 一覧の出典 | 輪郭の性格 |
|---|---|---|---|
| バショ `place` | **アーチ** | #4 大井町 / #6 蒲田 | 弧 |
| タイケン `experience` | **台形** | #26 藤沢 / #27 洋光台 | 斜め |
| ジョウホウ `info` | **角** | 予備2 / 鶴見 | 直角 |
| モノ `thing` | **二又** | 品川 / #22 恵比寿 | 切れ込み |

★4つは**輪郭の性格が全部違う**ものを選んである。小さく描いても混ざらないのは
このため。形だけ差し替えないこと。
★割り当ては**4ドメインで固定**（ユーザー確定）。一覧は駅ごとに46種あるが、
鋏痕は**マップのノードの形**と**ストックの絞り込み**でも同じ意味を持つので、
細かく分けるとその約束が壊れる。

**鋏痕は3か所で同じ意味を持つ**（文字を使わない分類）:
1. 券の縁の切り欠き 2. マップ上のノードの形 3. ストックの絞り込みアイコン

### 入鋏は垂直でなくてよい

`TicketPunch` は `edge`（4辺）・`t`（辺のどこか）・`tilt`（傾き・度）を持つ。
**切りたい辺を、好きな位置に、好きな傾きで**切り欠ける（ユーザー確定）。

★物理的に正しく描くための仕掛け … 鋏痕の形の**口から外側へ板（`NOTCH_LIP`）を
伸ばして**おき、その塊ごと**口の中点まわりに回す**。斜めに入れば口はそのぶん
広がり、券の縁は左右とも直線のまま残る＝実物の斜め入鋏。券の外へはみ出た分は
券の `overflow: hidden` が切る。
★板を伸ばさずに回すと、**縁に三角の紙のヒゲが残る**。

★陰は**口を除いた輪郭**（`notchContour`）にだけ落とす。閉じた輪郭を縁取ると
**券の縁そのものにも線が乗り**、切れ目ではなく「置かれた図形」に見える。

## 2-b. 改札鋏（`components/explore/Nipper.tsx` ＋ `lib/nipperSolid.ts`）

★**SVG で描く**。CSS の 3D 変形は使わない（design.md 冒頭）。

### ★★★形を合わせるための道具（11巡目に整備）

**`/dev/explore` の「Nipper」の先頭に、参考画像と同じ画角の1体を置いてある**
（`away = { x: 0.22, y: 0.62 }`・幅 300）。**形の合否はここで見る。**
四隅の4体は「掴んで動かすとパースが変わる」ことの確認用で、画角が違う。

数で合わせる指標（参考画像を実測した値）:

| 指標 | 参考 | 合わせ方 |
|---|---|---|
| 全体の縦横比 | **0.36 前後** | 投影後の bbox（`#frame` と `#lever` の合併）で測る |
| 頭が全長に占める割合 | 約 1/3 | |
| 奥／手前の柄の幅 | 約 0.6 | |
| 明るい左の縁の幅 | 幅の約 1 割 | 面取り `C` と柄の厚みで決まる |
| 腹（いちばん太い所） | 全長の約 6 割下 | 中ほどだと紡錘に見える |
| 明暗の幅 | **狭い**（中間調どうし） | 段の幅 `LIT_SPAN` で決まる |

★★**厚みを削って解決しようとしないこと**（12巡目の教訓）。11巡目に「明るい左の帯が
広い」のを柄を薄く・面取りを浅くして直そうとしたら、面が減って**板に見えるようになり
かえって悪化した**。参考の道具は**角を落とした厚い鍛造の塊**。正しい直し方は
**段の幅を広げて見える面を真ん中へ寄せる**こと（明暗の幅が狭い鋼になる）。

### ★★★機構 ── **ペンチ**（13巡目にユーザーが言葉で確定）

9〜12巡目は**頭を2つの塊として並べて**いたので、どう寸法を詰めても
**「2本の棒」**にしか見えなかった。正しい構造はユーザーの言葉のとおり:

> 先端は繋がっていて大まかな構造はペンチのような形です。ペンチの構造で、
> 先端の部分が太い箱にスリットが入ったような形状になっています。
> スリットの部分に紙が入ります。常時はバネで開いているので角度が広いです

| | 正 | 9〜12巡目の誤り |
|---|---|---|
| 先端 | **繋がっている＝箱ひとつ** | 2つの塊が並ぶ |
| 箱 | **太い箱にスリット**。★そこに紙が入る | 別々の頭に窓 |
| 腕 | 箱の裾から**ハの字に大きく開く** | ほぼ平行に垂れる |
| 開き | **常時バネで開いている**（角度が広い） | ほぼ閉じている |
| 手前（右） | **太い柄**。頭と一体の固定部。ほぼまっすぐ下 | |
| 奥（左） | **細く薄い梃子**。押すと寄る。★開く角はここで作る | |
| バネ | 開きを埋める**大きな輪**＋梃子に沿う長い脚 | 小さな輪2つ |

```
   ┌──────┐        頭 ＝ ひとつの太い箱
   │ ▮    │        ▮ = スリット（紙が入る）
   └┬────┬┘
   ╱      ╲         ここから2本の腕が**大きく開く**
  ╱   ◎    ╲        バネの輪が開きを埋める
 ╱          ╲
```

★★★**寸法の正は「正面から撮った写真」**（2026-08-28 にユーザーが提供）。
そこから実測して起こした値が `FRAME` / `LEVER` の駅の表。

| 指標 | 値 |
|---|---|
| 全体の縦横比 | **0.66**（1枚の目標画像から読んだ 0.36 では開きが足りなかった） |
| 頭が全長に占める割合 | 約 1/3 |
| 太い腕 | **左**（細い腕は右。★向きはこの写真に合わせてある） |
| スリット | **右の顎**にあり、**頭の天で口を開ける**（紙はそこから差し込む） |
| 腕の開き | 片側 13°・合わせて約 26° |

★**肩は斜めに顎へ繋がる**（水平の棚を作らない）。
★**顎どうしは重ねる**（幾何で突き合わせると隙間から地が見える）。

### 頭 ── 欠きとスリットを描く### 頭 ── 欠きとスリットを描く

★**9巡目の「ダイの窓は描かない」は撤回した。** あれは**真上から見る**前提の話で、
いまの画角は横なので**スリットは見えるのが正しい**（参考画像のすべてに写っている）。

- **欠き** … 頭の右上で肩を落とす（駅の station 表で `cx` と `hw` を同時にずらす）。
- **スリット** … `invert(slab(...))` で作った**凹み**。`lib/nipperSolid.ts` の
  `invert` は面を裏返すので、手前の蓋が自動で落ちて**覗き込んだ穴**になる。
- ★★**凹みは面の向きで塗らない。** 光が届かないので `NIPPER_PAINT.gap`（段の外の
  いちばん暗い色）で1色に塗る。段の中でいちばん暗い色を当てても、暗く落とした
  部品の上では**1段しか差が付かず溝に見えない**（10巡目に実測）。

### 立体（`lib/nipperSolid.ts`）

- `extrude(駅, z)` … 断面（面取りした八角形ひとつ）を y に沿って押し出す。
  駅は `[y, 半幅, 半分の厚み, x の中心]`。**曲線は一度も出てこない。**
- `tube(折れ線, r)` … 任意の3D折れ線に沿った**管**（バネの針金）。
- `slab` / `invert` … 素直な箱と、その裏返し（＝凹み）。
- `bossZ(r, z0, z1)` … z 軸まわりの短い多角柱。

### 彩色 ── フラットシェーディング（手で塗らない）

面の階調は**法線と固定光の内積を6段に量子化する**。グラデーション禁止。

- 光は**ほぼ真横（左）から、わずかに上・手前**。★これに**天からの拾い光** `SKY`
  （上を向いた面だけを持ち上げる）を足す。足さないと**天面と正面が同じ段**になり、
  見下ろしているのに塊の天が立たない（11巡目に実測）。
- 段の割り当ては **正面 = 3（基本）／天 = 4／左の側面 = 5／右を向く面 = 0**。
  ★正面を暗い段に置くと、白地の上で道具全体が黒っぽく沈む（11巡目に実測）。
- ★面取り `C` は **0.60**。0.45 は深すぎ（明るい左の帯が広く走る）／0.80 は浅すぎ
  （面が減って厚みが消え、**板に見える**。12巡目に実測）。
- ★★**段の幅（`LIT_SPAN`）は広く取り、見える面を真ん中へ寄せる。** 狭くすると
  左の縁が真っ白・右の縁が真っ黒になり、参考の道具（明暗の幅が狭い鋼）から離れる。
  段5は光へ正面から向いた面にしか出ない＝まれなハイライトでよい。
- ★**陰の手当ては群にまとめて1度だけ**。面ごとに手で塗らない。
  奥の平板は手前の柄の陰に入るので**ひと段（実際は2段）暗く**する。
  針金は磨かれた鋼なので段を下げない。
- 色は `NIPPER_PAINT.ramp`（暗い順の6段）＋ `gap`（凹み）＋ `cast`（影）。
  **有彩色は使わない**（画面の有彩色は券の紙だけ）。

### 隠れ ── 裏の面を落とし、奥から手前へ描く

裏の面を落とし、残りを**平均 z の遠い順**に描く。
★★**裏面判定の y の符号に注意**。法線は局所座標（`+y` が上）だが画面は y が下向きなので、
カメラの向きと内積を取ると **`n.z + n.y·a.y > n.x·a.x`**（`−` ではない）。
10巡目まで `−` にしていたせいで**上を向いた面が常に落ちていた** ―
見下ろしているのに頭の天面が一度も描かれず、絵が平たく見えていた。
★凹みは**別の群にして最後に描く**（同じ群に混ぜると、画家の順で頭の面に負ける）。

### 投影 ── 一点透視（7巡目に確定。**触らない**）

```
proj(p) = { x: p.x + p.z·away.x,  y: −p.y + p.z·away.y }
away = (鋏の位置 − 画面の中心) ÷ カメラの高さ
```

★★鋏は**掴んで画面内を自由に動かす**ので、この仕組みは必ず残す。
消失点は画面の中心で、**手前の面ほど中心から外へ逃げる**。

### 落ち影 ── 床に寝かせる

立ち姿の複製をずらすのではなく、**床へ倒れ込ませる**。

```
影(x, y) = { x: x − h·SUN.x,  y: 地面 + h·SUN.y }    h = 地面 − y
```

高いところ（頭）ほど**左へ遠く**飛び、接地（柄の先）では足元に触れる。
★**ぼかさない**。輪郭だけの多角形1枚を、群に1度だけ透かす。
★★輪郭は**2つの部品を合併してから**倒す（`hull`）。部品ごとに落とすと、高さの差だけ
横へずれて**2本の帯に割れる**（11巡目に実測）。

### 動き ── Framer Motion は使わない

指定は `framer-motion` の `type: "spring"` だったが、design.md 冒頭で禁止
（未インストール）。**`lib/spring.ts` の減衰振動＋rAF で同じ物理を作る**
（`stiffness` ＝ 引き寄せ `k`、`damping` ＝ 減衰 `d`）。★係数は既存の4つだけ。

| 局面 | 係数 | 手ざわり |
|---|---|---|
| 閉じる（入鋏） | `K_TRAVEL` / `D_TRAVEL` | わずかに行き過ぎる＝**ガチャンの衝撃** |
| 戻る | `K_SETTLE` / `D_SETTLE` | 行き過ぎずに復帰 |

- 軸は**頭の支点（0,0）**、角は **2.4°**。★小さくてよい ― 参考画像の姿勢は
  **すでにほぼ閉じている**（バネで少し開いているだけ）。大きくすると
  手前の柄が奥の本体を飲み込む。
- 毎フレーム **React を再レンダーしない**。ref に持った群の `transform` を直接書く。
- ★JSX 側の `transform` は **`want` ではなく「いまのバネの値」**で書く。`want` で
  書くと、押した瞬間の再レンダーで**終わりの姿勢へ一度飛んでから**動き出す。

## 4. ストック（STOCK）

- 入鋏済みの券が格子に並ぶ。**画像主体**、数百件に耐える。
- 絞り込みは**鋏痕の形**。
- 会期が近い券は縁が変わり、切れた券は落ちる。
- 券をタップ＝原寸に戻る。

## 5. マップ（NETWORK）

- 目標とする見た目は Vignelli の NYC 路線図系：
  **太い等幅の線が平行に走り、角は大きな円弧、駅は黒丸、乗換は白い抜き。**
- ノードの形＝鋏痕。1駅に複数件が付く場合に対応する。
- 駅をタップ→券のピンが立つ。**中央ほど大きく写真つき、端ほど小さい（LOD）**。
- 絞り込むと図が**必要な分だけに変形**する（レイアウトは決定的。前後を補間）。

## 7. デザインの制約（design.md より）

- **CSS の 3D 変形（`perspective` / `rotateX` / `rotateY`）は使わない。**

- 余白・文字・角丸は `lib/tokens.ts`、色は `lib/constants.ts` から引く。
  図形の座標は「目盛りの外」として印を付ける。
