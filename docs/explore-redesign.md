## 0. 言葉の方針（最優先）

- **画面に出る文字は一般語**。「提案 / ストック / マップ / プラン」。
- メタファー（鉄道・券・案内標）は**視覚だけ**で表現する。
  「本日の販売は終了しました」のような言い回しは使わない。
  空の状態は「今日の提案は以上です」程度の普通の文にする。
- 英字のラベル（`STOCK` / `VIA` / `TERM` など）はサインの語彙として使ってよい。

## 2. 券 ── 唯一の共通部品

1件＝1枚の券。場所によって**縮尺だけ**が変わる。

### ★組み方の正は **Vitsœ のラベル**（2026-08-28 にユーザー確定）

参照は3枚（AuBe のポスター／**Vitsœ のラベル**／Grilli Type の名刺）。
3枚に共通しているのは次の5つで、券はこれに従う。

1. 地は**紙か、ベタ1色**。券は**その色の紙そのもの**になる。
2. **文字は全部黒**。階層は色ではなく**大きさだけ**が作る。
3. **太い黒バー**か**極細の罫**で区画を割る。箱で囲わない。
4. **巨大な要素が1つだけ**。券では**題**（ユーザー確定）。
5. 色は幾何形か全面のどちらか。**文字には使わない**。

### 版面（幅 300 / 比 13:21 → 高さ 485）

```
　　　　　　　　　　　　　　　　　　  ← 全面がドメイン色の紙（紙の目を焼いてある）
  EXHIBITION              Nº 0143    nano caps ／ 通し番号
  ──────────────────────────────     罫（黒・1px）

  ┌────────────────────────────┐
  │           写真              │     ★周囲に余白をとった四角（裁ち落とさない）
  └────────────────────────────┘

  見えないものたちの庭                ★主役。display(26)/bold、最大2行
  音と光だけで構成された9つの部屋を…    body(13)、最大2行

        （余白は題の上下へ 3:5 で割る）

  ──────────────────────────────     罫
  会期      12.02 – 03.16            ラベル(和 micro ＋ 欧 nano) ／ 内容(body)
  SOON
  会場      東京都現代美術館・清澄白河
  VENUE
  ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘ ∘    ミシン目（穿孔）
  EXPLORE                 ▮▯▮▮▯     半券
```

- **段は3つだけ** … 題 `display`(26) ／ 内容 `body`(13) ／
  ラベル 和 `micro`(9)＋欧 `nano`(7)。比は 2.0 と 1.44 で design.md §5-2 を満たす。
- **余白は題の上下へ 3:5 で割る。** 片側だけに逃がすと、写真が無い券で
  中央がぽっかり空く（3巡目に実際にそうなった）。
- 期限が近いことは**色ではなくラベルの語**で伝える（`PERIOD` → `SOON`）。
  有彩色は紙の1色しか使わない。
- ★題と要約は `flexShrink: 0`。縮むと `-webkit-box` が**字の途中で切れる**。

### 紙の色 ── 黒が載る明るい4色

券は色紙になり黒い文字が載るので、**暗い色は使えない**
（forest / violet / wine の上では黒が沈む）。`SCHEME` の明るい4色を当てる。

| ドメイン | 色 |
|---|---|
| バショ `place` | sky `#509BF5` |
| タイケン `experience` | pink `#F76FA1` |
| ジョウホウ `info` | yellow `#F5E837` |
| モノ `thing` | orange `#FA6E31` |

### 紙のテクスチャは**下地**に

`public/paper-kraft.webp`（図形が焼き込んでいるのと同じ1枚）を
**色のすぐ上・文字の下**に `mix-blend-mode: multiply` で敷く。等倍・繰り返しなし
（★縮小しない。紙の目は高周波なので消える）。
★最前面に `overlay` で乗せると**写真も文字も霞む**（2巡目に実際にそうなった）。

### 券種（データの出自）
| 券種 | ラベル |
|---|---|
| 提案 | 券種の欧文（`EXHIBITION` / `BOOK` / `FOOD` …） |
| 入力（自分で書いた／声から拾った） | `SELF ISSUED` |

★「自分で書いた」と「声から拾った」は**同じもの**。手動か AI かの違いだけ。

### 鋏痕（入鋏の痕）

★**券の縁を切り欠く**形。大きさは**券の幅の 13%**。
★★券が彩度の高い紙になったので、切り欠きは**地との差だけで読む**。

**形の正は旧国鉄の鋏こん一覧**（46種・2026-08-28 にユーザー指定）。
一覧を見ると、鋏こんは例外なく「**券の縁が形の上辺**で、そこから下へ食い込む」
形で、輪郭は**直線と単純な弧が2〜4本だけ**。この規律から外れると鋏こんに見えない。

| ドメイン | 形 | 一覧の出典 | 輪郭の性格 |
|---|---|---|---|
| バショ `place` | **アーチ** | #4 大井町 / #6 蒲田 | 弧 |
| タイケン `experience` | **台形** | #26 藤沢 / #27 洋光台 | 斜め |
| ジョウホウ `info` | **角** | 予備2 / 鶴見 | 直角 |
| モノ `thing` | **二又** | 品川 / #22 恵比寿 | 切れ込み |

★4つは**輪郭の性格が全部違う**ものを選んである。小さく描いても混ざらないのは
このため。形だけ差し替えないこと。
★割り当ては**4ドメインで固定**（ユーザー確定）。一覧は駅ごとに46種あるが、
鋏痕は**マップのノードの形**と**ストックの絞り込み**でも同じ意味を持つので、
細かく分けるとその約束が壊れる。

**鋏痕は3か所で同じ意味を持つ**（文字を使わない分類）:
1. 券の縁の切り欠き 2. マップ上のノードの形 3. ストックの絞り込みアイコン

### 入鋏は垂直でなくてよい

`TicketPunch` は `edge`（4辺）・`t`（辺のどこか）・`tilt`（傾き・度）を持つ。
**切りたい辺を、好きな位置に、好きな傾きで**切り欠ける（ユーザー確定）。

★物理的に正しく描くための仕掛け … 鋏痕の形の**口から外側へ板（`NOTCH_LIP`）を
伸ばして**おき、その塊ごと**口の中点まわりに回す**。斜めに入れば口はそのぶん
広がり、券の縁は左右とも直線のまま残る＝実物の斜め入鋏。券の外へはみ出た分は
券の `overflow: hidden` が切る。
★板を伸ばさずに回すと、**縁に三角の紙のヒゲが残る**。

★陰は**口を除いた輪郭**（`notchContour`）にだけ落とす。閉じた輪郭を縁取ると
**券の縁そのものにも線が乗り**、切れ目ではなく「置かれた図形」に見える。

## 2-b. 改札鋏（`components/explore/Nipper.tsx`）

★**SVG で描く**。CSS の 3D 変形は使わない（design.md 冒頭）。

### ★★★前提 ── 券も鋏も同じ机の上にあり、それを真上から見ている

券は机に水平に置いてある。鋏も**同じ机に、上面を上にして**置いてある
（＝そのまま紙が水平に入る向き）。だから見えるのは**券の表面と鋏の上面だけ**で、
★**真上から見た鋏はほとんど長方形**になる。

6巡目まではずっと「側面の絵に厚みを足したもの」を作っていた。誤りは3つ:

1. **平面に短縮をかけていた。** 真上から見れば机の面に短縮は無い。
   天面は**回転しただけの長方形**でなければならない。
2. **高さの投影が大きすぎた。** 真上からなら高さはほとんど潰れる。
   高さは「消失点から外へ逃げる量」でしかない。
3. **ダイの窓を天面に開けていた。** ★**穴を開ける部分は上から絶対に見えない。**
   それを見せようとしていたのが歪みを固定していた。有彩色ごと撤去した。

### 投影 ── 真の一点透視

```
base(l, w) = l·L + w·W          ★L ⊥ W の**単位ベクトル**＝ただの回転
proj(l, w, z) = base(l, w) + z · away
```

| 記号 | 意味 |
|---|---|
| `L` | 長さ方向 `(-sinθ, -cosθ)`。θ=34°。頭が左上（券の方）を向く |
| `W` | 幅方向 `(cosθ, -sinθ)`。★`L` と**直交**。だから天面は長方形のまま |
| `away` | **(鋏の位置 − 画面の中心) ÷ カメラの高さ**。高さ1あたりの画面上のずれ |

★消失点は**画面の中心**。**高いところほど中心から外へ逃げる**ので、右下に置いた
鋏は天面が右下へずれ、その分だけ**左と奥の側面**が現れる。その細い帯に、初めて
参考写真の断面（上下の顎・鋲・バネ）が見える。
★`away` は**呼び出し側が渡す**（画面のどこに置いたかで決まるので）。
★★工具の高さは長さに対して小さいので、**側面は細い帯にしかならない**。それが正しい。

### 形は「平面の輪郭」が担う

真上からは側面がほとんど見えないので、**平面の輪郭だけが工具の顔**になる。
先端は四角く幅広（ホチキス）、首は細く、柄は太くごつい（ペンチ）。
★段は**同じ `l` に2点**置いて急に変える。なだらかに絞ると鍛造の工具ではなく
「骨」や「めん棒」に見える。

寸法は `[l, z, 半分の厚み, 半分の幅]` の背骨。`l–z` が参考写真の断面、
`半分の幅` が平面の輪郭。腕Aは背骨のまま、腕Bは `z` の符号を反転（鋏は鋲で
交差しているので、上の顎を持つ腕の柄は下に出る ― 符号の反転がそれを表す）。

### 真上から見えるもの

- **先端** … 下の顎が**消失点側へ**わずかに覗く（低いので）。
- **手元** … 上の柄が**外側へ**わずかに覗く。
- **口** … 上下の顎の隙間。**細い暗線**にしかならない。それが正しい。
  ★角丸の輪郭を付けないこと（太らせると帯ではなく黒い塊になる）。
- **バネ** … `l–z` 面にあるので、真上からは細い線。柄のあいだの帯にだけ覗く。
- **鋲** … 幅方向のピンなので、側面の帯に小さく出るだけ。

### 描き方 ── `Bar` 1つだけ

1. 底面を `side` で置く … 天面より消失点側へ出るので、そのはみ出しが**側壁**
2. 天面を `face` で置く
3. 天面に**細い反射の帯**を1本（鍛造バーの反射。★1本だけ。増やさない）

側壁が細いぶん、天面が平板に見えないよう帯で金属らしさを出す。
影も**ぼかさない1枚の面**。階調は**無彩色の3つ**のみ。
★★**有彩色は使わない。** 画面の有彩色は券の紙だけ。

★描く順は**低い方から**。顎と柄で上下が入れ替わるので4分割して置く。

## 4. ストック（STOCK）

- 入鋏済みの券が格子に並ぶ。**画像主体**、数百件に耐える。
- 絞り込みは**鋏痕の形**。
- 会期が近い券は縁が変わり、切れた券は落ちる。
- 券をタップ＝原寸に戻る。

## 5. マップ（NETWORK）

- 目標とする見た目は Vignelli の NYC 路線図系：
  **太い等幅の線が平行に走り、角は大きな円弧、駅は黒丸、乗換は白い抜き。**
- ノードの形＝鋏痕。1駅に複数件が付く場合に対応する。
- 駅をタップ→券のピンが立つ。**中央ほど大きく写真つき、端ほど小さい（LOD）**。
- 絞り込むと図が**必要な分だけに変形**する（レイアウトは決定的。前後を補間）。
- **県が違えば別の島**にして破断線で繋ぐ（距離では判定しない）。
