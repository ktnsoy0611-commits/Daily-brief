## なぜ作るのか（目的）

このアプリは **時間管理でもタスク管理でもない**。
**AI が先回りして「いま自分にとって最適なもの」を差し出す場**であり、
仕事も週末も余暇も同じ種類の提案として扱う。

ホームはその**玄関**で、3アプリの枠を越えて情報が一元化される場所。
起動して最初に見る画面であり、ここから各アプリへ降りていく。

## ここに至る経緯（第18〜33便。詳細は `docs/redesign-ideas.md`）

出発点は「上に候補のピルが並び、下に図形が積もる」という1枚の絵で、
ユーザーが**「ピルが形を変えて gravity に落ちるのが、デザインと機能がうまく噛み合っている」**
と評価したもの。そこから16往復して、次が固まった。

- **置き場の規則は1本だけ** ―― 日付が無いものは帯（上）、日付が付いたものは山（下）。
- **形に意味を持たせない**（角の数＝義務の強さ、などは全部却下）。形はジャンルの札。
- **印（円＋記号）は触れる部品にだけ付く**。帯のピルには付けない
  （列に印が並ぶと**印が「模様」になって印でなくなる**）。
- **色は帯の上段・提案の丸・未読のバッジにしか出さない**。骨格は白と墨。
- **和文は太らせない・詰めない・大きくしない**。迫力は英語（Archivo 900）が担当。
- **大きな英語は1画面に1つ**（`TASK` と `SUNDAY` が同時にいたのが「ごちゃごちゃ」の正体だった）。
- 配色は参照画像から **`tools/extract-palette.py` で画素を測って**決めた（目分量で色を書かない）。

**却下された案を蒸し返さないこと。** `docs/redesign-ideas.md` に理由つきで全部残してある。
