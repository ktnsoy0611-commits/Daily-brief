# 参照（2026-09 の改修）★リンクはいつでもここから開く

★★★**何のための参照か で3つに分ける。** これを混ぜると、骨格の話に空気の参照を
持ち込むような取り違えが起きる（2026-09-06 に整理し直した）。

---

## 0 ── 自分自身（最優先の参照）

★★★**いちばん良かった画面は、外の参照ではなく「このアプリの GRAVITY ＋ ピルの帯」だった。**
新しい案は、まずここと比べる。

| 何が効いているか |
|---|
| **形＝状態**（ピル＝未決／図形＝決定） |
| **変態の瞬間＝状態が変わる瞬間**（引き下ろすと図形になって落ちる） |
| **ボタンが1つも要らない**（承認＝引き下ろす／却下＝上へ払う） |
| **画面に2種類しかない**（ほかはラベル1行と日付の活字だけ） |

## 1 ── 骨格の参照（ページ全体がどう組まれているか）
★**ホームを作るなら、ここを見る。**

| | URL | 何を採るか |
|---|---|---|
| 大洋LINKS | https://links.taiyo-p.co.jp | **同じ形の章を6回くり返す**。Hero は情報ゼロ。各章は〈英語ラベル → 和文の見出し → **代表4枚** → 詳細へ〉で完全に同一、**変わるのは地の色だけ**。深さは別ページへ逃がす |
| Google Labs | https://labs.google | **同じカードが縮尺を変えて3回出る**（大1 → 中5 → 小12＋フィルタ）。新しい部品を足さず**同じ部品を縮める**。時間の軸は終盤に一度だけ |

## 2 ── 部品の参照（1つの単位がどう作られているか）
★**提案カードを作るなら、ここを見る。**

| | 何を採るか |
|---|---|
| Google Labs のカード | 色ベタの器 →〈**変わった形の窓＝写真** → 題 → 説明 → ピル〉。**順番と余白は全カードで同一**、変わるのは色と窓の形と写真だけ |
| 大洋のフォルダ | **英語ラベル ＋ 和文の題 ＋ 花形の丸ボタン**。重なりの深さが階層。「進む」は必ず1つの形 |
| Heap（年金アプリ） | **円ひとつだけで、装飾も図解もグラフも入力欄も全部やる**。語彙を増やさないことが統一感の正体 |

## 3 ── 空気の参照（色・形・気分）
★テイストは**統一されていない好みの寄せ集め**。**骨格や部品の判断には使わない。**

| | 何が効いていたか |
|---|---|
| Visorefont | 丸い display 体の巨大な見出し／**色ピルが画面外へはみ出して並ぶ**（＝出発点のピルの帯の元） |
| Events アプリ | 太い黒の見出し／回転した図形の中にラベル／下から覗くカードの束 |
| ステッカー文字 | **語が図形の器にぴったり収まる**。器の形＝語の構造 |
| Kleurvorm ／ Gradient World | 半透明が重なって第3の色。**どちらもポスターでアプリ画面ではない** |
| 粒のグラデーション図形 | 幾何形にざらついたグラデーション |

## ★参照の使い方（ユーザー指定）
- **そのままコピーしない。** 特徴を分析し、軸として使う。どこを軸にするかは提案する側が決める。
- **無理につなげない。** 空気の参照は空気の話にしか使わない。
- ★★**部品はそのままでは使えない。** 規約に合わせて手を入れる前提。
- ★新しい参照は「**骨格／部品／空気**」のどれかを添えてもらう（分からなければこちらで分類する）。
