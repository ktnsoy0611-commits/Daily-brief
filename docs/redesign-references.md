## 第23便で追加した参照（4 骨格＋規則の出どころ）

ユーザーが「割と近くてかつ洗練されている」と言った5枚。**色や形・コンポーネント・文字を見習う**。
ただし**英語だから成立している部分がある**ので、そこは分けて扱う（下の「和文の壁」）。

1. **The Now Company / ブランドガイドライン**（Swiss・International Typographic Style）
   … 極太のグロテスク＋語尾のピリオド（`Power. Life. Bold. Grow.`）、**全面のベタ塗り**、
   ページの半分を占める巨大な円、黒帯に白抜き。**角丸・影・質感がゼロ**
2. **Friends From The City**（Helvetica Now Display）
   … ★**地が灰 `#D9D9D9`**。小さな色の丸を「印」として使い、黒い面を**色として**堂々と使う。
   矢印入りの円が繰り返しの装置
3. **Missy & Co** … 生成りの地に**silhouette の違う図形**（花・星形・八角・アーチ・二連アーチ）。
   ★**「形の理由」の参照はこれ**
4. **ポッドキャストの表紙6枚** … ★**このアプリにいちばん近い構造** ――
   生成りの見出し帯 ＋ **色の面** ＋ **その上の大きな図形1つ**（円・八角・クローバー・×・菱形）＋
   **左上に置いた名前**。1枚あたり**色は2つ**
5. **NORI** … 黒地。半円・カプセル・スクワークル・アーチという**図形の語彙**と、
   色に名前を付けた一覧（Kobi Pink／Mountain Meadow／Laser Lemon／Royal Blue／Red Orange）

### ★★★5枚から抜いた7つの規則
1. ★★★**色は「面」であって「物」ではない** … 参照では色がページそのものか、
   ページの半分を占める図形1つ。**小さな色の粒を撒くと紙吹雪、面にするとポスター**
2. **1画面に色は2つまで。地は数えない** … 6色は**在庫**であって**同時使用数ではない**
3. **地は白でもクリームでもなく灰** … 灰はどんな色も裏切らず、**黒が色として立つ**。
   クリームは黄を含むので黄・桃と喧嘩する
4. **黒は「文字の色」ではなく「1色」** … 黒の面積が入ると隣の高彩度が急に大人になる。
   ★**暗い色を新しく作るより、黒をそのまま面で使うほうが確実**
5. **影・グラデーション・質感がゼロ** … 丸いところは完全な半円で、**中途半端な角丸がない**
6. **文字は面の「左上」に置く。中央に置かない** … ★**中央揃えにした瞬間にバッジ・シールになる**
7. **小さい文字はうんと小さく** … ラベルは 8〜9px・字間 .2em・大文字。**中くらいの文字を作らない**

### ★★★和文の壁（英語だから成立していること）
- 欧文は**アセンダとディセンダで行に凹凸**が出るので、字間を詰めて黒く潰しても語の輪郭が残る
- 和文は**全部が同じ正方形の枠**に収まるので、太らせると**輪郭が消えて黒い長方形**になる
- ★**規則** … **和文は太らせない・詰めない・大きくしない**。
  迫力は**英語（Archivo 900・字間 −0.045em）が担当**し、
  **和文は 500〜700／字間 +0.02〜0.04em／行間 1.7〜1.9**
- ★このアプリは**すでに大きな英語（TASK・SUNDAY）を持っている**ので構造は正しい。直すのは和文側
